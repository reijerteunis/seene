# Seene — Claude Code entry point

Read [AGENTS.md](AGENTS.md) first. It is a short index that routes to the document covering
the work at hand. It is referenced rather than imported so that only the relevant instructions
enter the session.

Ticket work uses the shared harness: `/seene-harness SEENE-001` to start,
`/seene-harness resume SEENE-001` to continue. Codex uses the same
[workflow](docs/harness/workflow.md), commands and journal, so read the existing
`docs/harness/history/<ticket>/` records before acting.
